# Approval Gates

Automatic authorized classes: READ, DRAFT, BRANCH_WRITE, SAFE_LOCAL_REPAIR, SANDBOX_WRITE, PREVIEW_WRITE, TEST, VALIDATION, DOCUMENTATION.

Explicit scoped operator approval is required before production deployment, protected/default branch merge, production DB/schema/RLS changes, secret creation/rotation/revocation, DNS/domain changes, payments/spend, live/public publishing or advertising, customer/employee communications, permission escalation, destructive actions, repository transfer/deletion, irreversible migration, OS reset/reinstall, or disk formatting.

Never infer approval from silence.
